# Student Marks Calculator (SQLite, black and gold)

Pages: index.html (Dashboard), calculator.html, students.html, reports.html.
Shared code: js/db.js (SQLite via sql.js, stored in the browser's IndexedDB), css/style.css (theme).

## Run locally
Open the folder in a terminal and run `python -m http.server 8000`, then visit http://localhost:8000.
(An internet connection is needed for the sql.js library and Google Fonts.)

## Publish on GitHub Pages
Upload everything in this folder to your repository root, commit, and the site updates.
